📋 Schritt-für-Schritt

1️⃣ Terminal: Alte Dateien löschen

Terminal
cd ~/projects/taxipro-dispatch git rm -rf . git commit -m "Clear: Ready for Next.js rebuild"

2️⃣ Alle Dateien unten kopieren (mit Copy-Buttons!)

Jede Datei mit dem "COPY"-Button kopieren und in den richtigen Ordner einfügen:

  • package.json → root/
  • app/layout.tsx → app/
  • app/(auth)/login/page.tsx → app/(auth)/login/
  • usw...

3️⃣ Terminal: npm install

Terminal
npm install

4️⃣ Terminal: Umgebung einrichten

Terminal
cp .env.example .env.local

Editiere .env.local und trage deine Supabase DATABASE_URL ein!

5️⃣ Terminal: Datenbank & Test

Terminal
npx prisma migrate dev --name init npm run dev

Browser: http://localhost:3000/login | Login: admin@example.com / admin123

6️⃣ Terminal: Git & Push zu test/

Terminal
git add . git commit -m "feat: Complete Next.js rebuild with Auth, Dashboard, Prisma" git branch test git push origin test

7️⃣ Browser: Testen

GitHub Actions läuft jetzt (2-3 Min). Dann teste im Browser:

https://taxipro-dispatch.pages.dev/?branch=test

8️⃣ Wenn OK → Merge zu main

Terminal ODER GitHub UI
git checkout main git merge test git push origin main
✅ FERTIG! Deine App ist jetzt LIVE auf Cloudflare Pages! 🚀
