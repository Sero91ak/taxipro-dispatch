# TaxiPro Dispatch 2.1 – sichere Vorschau

Diese Version liegt im **bestehenden** GitHub-Repository `Sero91ak/taxipro-dispatch`, zunächst unter `/v2/index.html`.

**Nur Testdaten.** Aufträge, Schichten, GPS-Standorte und Nachrichten werden in der Vorschau lokal im Browser gespeichert und NICHT an andere Geräte übertragen. Es gibt kein produktives Login, keine Kundenmigration, keinen sicheren Upload von Krankenbeförderungsscheinen und keine Verbindung mit Google Kalender.

Die bisherige `dispatch.html` und `driver.html` bleiben bis zur Inbetriebnahme einer sicheren Mehrbenutzer-API unverändert. Keine Echtdaten in die öffentliche Vorschau eingeben.
