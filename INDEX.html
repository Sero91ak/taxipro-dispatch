🚀 Copy-Plan (30 Min)

Schritt-für-Schritt: Folge dieser Anleitung und du bist fertig!

1️⃣ Alte Dateien löschen

cd ~/projects/taxipro-dispatch
git rm -rf .
git commit -m "Clear: Ready for Next.js rebuild"

2️⃣ Neue Dateien kopieren

  • Downloade alle Dateien aus /mnt/user-data/outputs/
  • Kopiere sie in dein taxipro-dispatch/ Verzeichnis
  • Beachte die Ordner-Struktur! (app/layout.tsx geht in app/, nicht in root!)

3️⃣ Ordner-Struktur ggf. erstellen

mkdir -p app/{api,\(auth\),\(dashboard\)}/{customers,trips,import,export,monthly}
mkdir -p components/{dashboard,common,forms,modals}
mkdir -p lib types prisma docs public
mkdir -p .github/workflows

4️⃣ package.json umbenennen

cp taxi-app-package.json package.json

5️⃣ npm install

npm install

6️⃣ Umgebung einrichten

cp .env.example .env.local
# Jetzt .env.local editieren:
# DATABASE_URL = "postgresql://..."  (von Supabase)
# NEXTAUTH_SECRET = "..." (openssl rand -base64 32)

7️⃣ Datenbank migrieren

npx prisma migrate dev --name init

8️⃣ Test starten

npm run dev
# Öffne http://localhost:3000/login
# Login: admin@example.com / admin123

9️⃣ Git pushen

git add .
git commit -m "Feat: Complete Next.js rebuild"
git branch test
git push origin test

🔟 Deployen & Freigeben

Browser → https://taxipro-dispatch.pages.dev/?branch=test → Test → OK → Merge test zu main ✅

❓ FAQ

F: Wo finde ich all die Dateien zum Download?

A: In /mnt/user-data/outputs/. Alle Dateien sind dort bereit.

F: Muss ich wirklich alle Dateien aus outputs/ kopieren?

A: Ja, alle aus der Tabelle oben (die mit ✅ READY). Die "Später" Dateien brauchst du NICHT jetzt.

F: Kann ich direkt in main pushen oder in test/?

A: Immer erst in test/ pushen. Du prüfst im Browser, dann mergen zu main.

F: Wie lange dauert das Setup?

A: Ca. 30 Minuten: Download (5 min) + Kopieren (10 min) + npm install (10 min) + Test (5 min).

F: Was wenn npm install Fehler hat?

A: Lösche node_modules/ und package-lock.json, dann npm install erneut.

F: Muss ich Google Kalender jetzt einrichten?

A: Nein. Das kommt in Phase 2. Jetzt reicht das Grundgerüst.
